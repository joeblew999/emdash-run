# Agent guidance lives in `docs/agents/`

**Read `docs/agents/` — that folder is the one copy, so it cannot drift.**

- **`docs/agents/README.md`** — start here, with its first section, *EmDash first*: what EmDash
  already ships (three CLIs, the agent skills in `site/.agents/skills/`) and the rule that nothing is
  built here before checking them. Then the rules, the checks to run, the layout, the tools.

Nothing agent-facing is kept in this file on purpose. Two copies of guidance drift apart, exactly
like two copies of a task list — and this repo has already been bitten by that once.
