## Dropped, with the reason

- **The proof site signed in and used for `live:backup`, `content:pull`, `model:sync -- --live`.**
  All three pass against a production build on this machine, which is the same code and the same
  kind of credential. The real-deployment run is stage 3, on a site that is wanted.
- **Cloudflare Access, and a `live:login` task for a service token.** Access was decided against:
  in production it switches off every other sign-in, the script's passkey included.
- **Email-link sign-in.** Needs an email service first; GitHub gives people the same thing with
  less to set up.
- **A git hook for `site:check`.** Decided against in the stages plan.
