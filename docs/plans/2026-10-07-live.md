## The tasks this plan builds

| task | steps, as planned — each confirmed or changed by stage 2 |
|---|---|
| `live:ship` | `wrangler whoami` → `live:check` → `wrangler d1 time-travel info DB` → `wrangler deploy --strict --message <date>` → `wrangler deployments status` → `emdash migrate --check` → the live site answers `emdash schema list --url LIVE_URL` |
| `live:undo [version]` | `wrangler whoami` → `wrangler rollback [version] -y -m …` → `emdash migrate --check`; says a rollback does not undo a migration |
| `live:logs` | `wrangler tail` |
| `live:backup` | `wrangler d1 time-travel info DB` → the SQL dump if it works remotely → `emdash site export --url LIVE_URL`; ends by saying what none of them holds: the media bucket and `EMDASH_ENCRYPTION_KEY` |
