# 2026-10-05 — Registry, plugin panel, and harness hygiene

**Status:** active (partially done — see the Done list at the bottom)

The local plugin registry now runs, so the old "blocked upstream" note was wrong and has
been removed. What remains is finishing the registry wiring and the geometry panel.

## Open

### 1. Wire the plugins site to the local registry

`apps/plugins-site` (the registry's web UI, `plugins.emdashcms.com`) calls
`registryLoader()` with **no options**, so it is hardcoded to the hosted registry —
`https://registry.emdashcms.com` is baked into `@emdash-cms/registry-loader`, and the
client has no env override.

**Done means:** the UI at `:4330` lists packages from our local registry (`:8788`), proven
by the registry's own log showing the `searchPackages` request at page-load time.

**How:** `src/live.config.ts` in the clone needs
`registryLoader({ aggregatorUrl: process.env.EMDASH_REGISTRY_URL })`. Editing `.src/` by
hand is not allowed (it is regenerated), so this needs a **scripted, idempotent patch**
applied by a task after `src:clone-emdash` — and it must fail loudly if the upstream line
changes shape.

### 2. Live geometry in the panel

The panel (`plugins/plat-trunk/src/admin/index.tsx`) renders only what is stored on the
entry. It should fetch stats from the plat-trunk worker (`cad.ubuntusoftware.net`) and add
a validation badge + deep link to the CAD viewport.

**Blocked on:** the worker's endpoint contract (path, response shape, auth). Not startable
without that.

### 3. Re-seed the live D1

The deployed D1 was seeded **before** `geometry_meta` was added to `config/cad.seed.json`,
and a seed only applies to a fresh database — so the live panel shows only Part number and
Material, while local shows the full geometry block.

**Done means:** the live part editor shows Vertices / Faces / Bounding box / Validation.

**How:** either re-seed the live D1 (destructive — it is seeded demo content) or update
the entries through the live admin. There is no dev-bypass in production, so a scripted
path needs an MCP token minted on the live site.

### 4. `docs/plugin-catalog/` is stale

Generated by `mise run plugin:catalog` (GitHub discovery). It predates the registry and
has not been regenerated. Either refresh it or drop it — the registry is the discovery
path now.
